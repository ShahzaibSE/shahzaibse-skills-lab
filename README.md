# Agent Skills Lab

Version-controlled skill labs and reasoning workflows for Claude Code — treating AI behavior as auditable, reviewable code.

---

## 📌 Purpose

This repository contains a structured collection of **Claude Code skills, reasoning patterns, and tool workflows** managed using standard Git practices.

The goal is to apply **software engineering discipline** to AI tooling:
- Version control for AI behavior
- Reviewable changes via pull requests
- Reproducible local setups
- Safe evolution of prompts, skills, and reasoning workflows

Think of this as **GitOps principles applied to AI skills**.

---

## 🧠 What Are “Skills Labs”?

In the context of Claude Code, a *skill lab* is:
- A reusable reasoning or workflow pattern
- A structured prompt or system behavior
- A tool-assisted reasoning setup (debugging, refactoring, system design, etc.)

Each skill is treated as **code**, not ad-hoc prompts.
